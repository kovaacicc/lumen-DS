# Lumen DS — Cross-Sell & Up-Sell Recommendation System

A machine learning pipeline that segments B2B customers, discovers product associations, and serves real-time cross-sell and up-sell recommendations through a REST API.

---

## Pipeline Overview

```
data/raw/LUMEN_DS.csv  (~1.3M invoice rows, B2B)
         │
         ▼

         │
         ▼
data/processed/data_clean_final.csv  (~930K rows after cleaning)
         │
         ▼
[02] customer_segmentation.ipynb
     RFM + KMeans (K=4)
         │
         ▼
  rfm_segments.csv
         │
    ┌────┴───────────────────┐
    ▼                        ▼
[03] market_basket    [04] cross_sell_recommender

         │                    │
         ▼                    ▼
 association_rules.csv   models/recommender/*.pkl
                         data/processed/recommender/*.csv
                              │
                              ▼
                       [05] upsell_model
                            cluster-conditional
                            item popularity
                              │
                              ▼
                       data/processed/upsell/*.csv

                  ┌───────────┴──────────────┐
                  │       api/main.py        │
```

## Setup

**Requirements:** Python 3.10, Conda

```bash
# 1. Create environment
conda create -n lumen-ds python=3.10 -y
conda activate lumen-ds

# 2. Install notebook dependencies
pip install pandas==2.3.3 numpy==2.2.6 scikit-learn==1.7.2 xgboost==3.2.0 \
    imbalanced-learn==0.14.1 mlxtend==0.23.4 matplotlib seaborn \
    jupyter ipykernel joblib

# 3. Install API dependencies
pip install -r api/requirements.txt

# 4. Register Jupyter kernel
python -m ipykernel install --user --name lumen-ds --display-name "lumen-ds"
```

Place the raw dataset at `data/raw/LUMEN_DS.csv` before running any notebooks.

## How to Run

Open Jupyter from the project root with the `lumen-ds` kernel active, then run notebooks **in order**:

| Step | Notebook | Key Output |
|------|----------|------------|
| 1 | `data_cleaning.ipynb` | `data_clean_final.csv` |
| 2 | `customer_segmentation.ipynb` | `rfm_segments.csv` |
| 3 | `market_basket.ipynb` | `association_rules.csv` |
| 4 | `cross_sell_recommender.ipynb` | `models/recommender/recommender_xgb.pkl` |
| 5 | `upsell_model.ipynb` | `data/processed/upsell/*.csv` |

Steps 4 and 5 can run in parallel once Steps 1–3 are complete.

> For full details on each step, expected outputs, and troubleshooting, see [RUN_BOOK.md](docs/runbooks/RUN_BOOK.md).

## API

Start the server from the project root:

```bash
conda activate lumen-ds
uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

Interactive documentation (Swagger UI): `http://localhost:8000/docs`

### `POST /cross-sell`

Returns up to 5 product group recommendations for a customer, each with up to 5 specific item suggestions.

```bash
curl -X POST http://localhost:8000/cross-sell \
  -H "Content-Type: application/json" \
  -d '{"customer_id": 12345, "item_codes": ["03650", "2158"]}'
```

```json
{
  "customer_id": 12345,
  "recommendations": [
    {
      "product_group": "PC016",
      "confidence": 0.4642,
      "items": [
        {"item_code": "BOE001-TY8.375", "confidence": 0.1098, "avg_price": 6.02}
      ]
    }
  ]
}
```

### `POST /up-sell`

For each item code provided, returns premium alternatives from the same product group personalised to the customer's segment.

```bash
curl -X POST http://localhost:8000/up-sell \
  -H "Content-Type: application/json" \
  -d '{"customer_id": 12345, "item_codes": ["03650", "03673"]}'
```

```json
{
  "customer_id": 12345,
  "recommendations": [
    {
      "current_item": "03650",
      "product_group": "PC001",
      "current_tier": "standard",
      "current_avg_price": 0.0,
      "premium_alternatives": [
        {"item_code": "2158", "confidence": 0.0495, "avg_price": 78.99}
      ]
    }
  ]
}
```

Both endpoints accept requests with no `customer_id` — unknown customers fall back to population averages (cross-sell) or skip cluster personalisation (up-sell).
